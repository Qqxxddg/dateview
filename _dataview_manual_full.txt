第2章 基础数据
2.1 概述
基础数据菜单下包含服务配置、数据源配置、定时任务、数据字典、多语言配置五
个模块，在服务配置中添加相应的 JDBC/HTTP 服务，数据源或定时任务根据服务配置
设置相应输入字段等从而获取到布局所需的对应数据，数据字典中的数据在系统初始
化时会添加一部分系统默认数据，之后若有需要可自行增删字典数据。
2.2 服务配置
服务配置为业务系统中的 HTTP 服务器或数据库，其作为数据源和存储过程执行的载
体。服务配置包含服务编号、服务名称、服务类型、IP、端口、服务前缀、数据库名
称、用户名等信息，且不同的服务类型需配置不同的属性，可根据查询条件服务编号、
服务名称、服务类型查询对应的服务，且可以添加、删除、编辑相应数据。
图2-1
 添加/编辑/删除服务
 点击“添加”，弹窗如下图所示，当服务类型为 HTTP 时需配置服务名称（必填）、
IP（必填）、端口（必填）、服务前缀、用户名、密码、连接超时（必填）、接收超时
（必填）；当服务类型为 JDBC 时需配置服务名称（必填）、数据库类型（必填）、IP
（必填）、端口（必填）、服务前缀、用户名、密码、数据库名称。

﹘数据库名称：JDBC 必填，JDBC 数据库名；

2.3 数据源配置
针对某一个服务器的具体参数查询规则配置，支持 HTTP 接口和 JDBC，通过该数据
源可进行具体的数据查询，可通过配置输入输出参数进行完整的数据源描述。数据源
配置包含数据源编号、数据源名称、服务编号、服务类型、数据源类型、内容、输入
参数、输出参数等，可根据查询条件数据源编号、数据源名称、数据源类型查询对应
的数据源，且可以添加、删除、编辑、导入、导出、测试相应数据。

2.4.3 添加存储过程
存储过程主要用于定时查询数据，将获取的数据作为数据查询的缓存使用，通过该
方式可以完成复杂的数据查询操作，同时可以提供数据缓存，防止系统压力过大。存
储过程包含存储过程名称、关联服务、方法名、存储过程、状态等，可查询、添加、
删除、编辑相应数据。

第4章 布局设计
4.1 概述
页面布局为 DataView 的核心资源，该页面主要用于进行页面布局展示及管理，可
以在此页面进行布局的添加、预览及删除等，并提供搜索功能。布局设计，按布局类
型不同，其可供使用的元件、可供编辑的属性都不同。例如查询表格类型的布局，可
使用表单元件和表格元件，可编辑修改表单属性和表格属性；查询图表类型的布局，
可使用表单元件和图表元件，可编辑表单属性；统计看板类型的布局，可使用图表元
件。
页面支持按布局类型、布局名称查询布局，支持按卡片/列表方式显示各个布局，
适用于布局较多时的快速查找。页面可分组管理，用于页面较多时的分类，比如调度
页面和仓储页面可划分不同组。
